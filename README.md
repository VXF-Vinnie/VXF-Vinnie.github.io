# VXF-Vinnie.github.io

Personal portfolio site for **Vincent Farfan**, Computer Science student at Arizona State University: B.S. with a software engineering focus (May 2027), then an accelerated M.S. with an Artificial Intelligence focus (May 2028).

Live site: https://vxf-vinnie.github.io/

## Pages

- `index.html` — Hero, featured projects, about + now & next, contact CTA
- `portfolio.html` — Projects
- `resume.html` — Experience, projects, education, skills, and a downloadable PDF resume
- `contact.html` — Email, LinkedIn, GitHub, and other links

## Built with

HTML, CSS, JavaScript, Bootstrap 5, and Bootstrap Icons. Hosted on GitHub Pages.

## Updating the resume

Replace `assets/Vincent_Farfan_Resume.pdf` with a newly exported PDF (keep the same file name).

## Images

- `images/projects/` — project visuals used on the home and Projects pages (SCRUBIT screenshot, compiler architecture diagram and a cropped version for cards)
- `images/og-card.png` — 1200×630 link-preview image for LinkedIn, iMessage, Slack, etc.
